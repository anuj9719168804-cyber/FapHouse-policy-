## 🚀 GitHub Pages Deployment

1. Upload `index.html` to your repository.
2. Open Settings → Pages.
3. Select `Deploy from a branch`.
4. Choose the `main` branch.
5. Select `/(root)` as the folder.
6. Click Save.
7. Wait for deployment to complete.
